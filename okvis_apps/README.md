# okvis_apps

Dataset / bench applications for OKVIS2-X (`okvis_app_synchronous`, `okvis2x_app_synchronous`, `dbow2_test`, RealSense apps).

The binaries are compiled by the **top-level `okvis` superbuild** (`-DBUILD_APPS=ON`, the default in `tools/cross/colcon*.meta`). This directory is also a colcon package (`package.xml`, plain CMake) that depends on `okvis`, so `colcon build --packages-up-to okvis_apps` builds and installs the apps; on its own it only installs `scripts/bag_creator.py`. A standalone build against `find_package(okvis)` is not possible today because the exported `okvis::MultisensorProcessing` link interface references the non-exported `SRL::Supereight2` target (mow-e T-0113).

`okvis_app_synchronous <config.yaml> <dataset>/mav0/ [save-dir]` writes the causal / final trajectories and, since T-0113, `frontend_stats.json` (keypoints per frame, stereo and map matches, front-end ms mean/p99, `engine_loaded`, loop closures) to the save dir. T-0129 adds map-matching quality: `mean_map_reproj_px` (the per-frame value `matchToMap` compares with `strictReprThreshold` before running 3D-2D RANSAC; `_legacy_px` = upstream's per-candidate definition), `mean_map_match_px`, `map_duplicates_dropped_per_frame`, `ransac_fail_frames_ratio` (first-RANSAC failures / map frames), `inlier_ratio_p50`. Diagnosis-only env switches: `MOWE_MAP_MANY_TO_ONE=1` (upstream many-keypoints-per-landmark rule on the XFeat path), `MOWE_XFEAT_NO_OFFSETS=1` (integer keypoints), `MOWE_RANSAC_PROBE=1` (measure the inlier ratio on frames that did not trigger RANSAC).
